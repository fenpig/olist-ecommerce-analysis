# T12：核心指标 SQL 结果说明

本目录仅保存 T12 的脱敏汇总结果说明，不包含订单明细、客户信息、连接凭据或数据库导出文件。

## 数据来源与执行方式

- 数据源：MySQL 视图 `vw_order_analysis`，订单粒度为一行一个 `order_id`。
- 配送查询：[sql/05_delivery_metrics.sql](../../sql/05_delivery_metrics.sql)。
- 评分查询：[sql/06_review_metrics.sql](../../sql/06_review_metrics.sql)。
- 两个脚本只包含 `SELECT` / `WITH ... SELECT` 查询；不创建、替换或修改任何数据库对象。

## 已固定的样本与口径

- 配送可用样本：`is_delivery_eligible = 1`；延迟率的分母固定为该样本。
- 正式配送延迟订单：`is_delivery_eligible = 1 AND delay_days > 0`；`delay_days` 是实际送达日期减预计送达日期的日历日差。
- 全量 `is_delayed = 1` 仅是日期差字段分布，不是正式配送延迟率的分子。
- 交运至送达时长：仅 `is_transit_duration_eligible = 1`，单位为连续天数。
- 评分关系样本：`is_review_relation_eligible = 1`；平均评分、低评分率和高评分率均使用该样本。
- 低评分为 1–2，高评分为 4–5；主评分为最新有效评价，不平均多条评价。
- 日期异常对照：主口径保留全部符合条件订单；对照口径额外排除 `has_date_anomaly = 1`。该对照仅比较描述性指标，不构成关联、因果或业务结论。
